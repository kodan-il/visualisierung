Visualization Design (What-Why-How)

In the last weeks, you learned a lot about the

  • what (what kind of data is it?)
  • why (which tasks do you want to perform on the data?)
  • how (how to encode data with marks & channels, how to manipulate, facet and reduce your data)

In this assignment, you will put these skills to use to create your own visualization design.

When you are finished, zip the assignment's folder (all given files, + your sketches, - the node_modules folder) and upload the zip file to the Moodle platform by Wednesday 23rd April, 23:59.

If you have questions regarding the tasks, please ask us directly in the lab class sessions or use the forums on Moodle, such that all students can benefit from the answer.

Also, please prepare your assignments for the next lab class after the deadline. There will be questions about your solutions in the graded test.

Tasks

Task 1: The What (25%)

Determine the dataset type of the given data (contents of the penguins.csv), the attribute types (categorical, ordinal, quantitative) as well as their ranges / possible attribute values for all the attributes.

Write your answer in the file "what.md".

Task 2: The Why (25%)

Part 1

Data scientists are interested in answering the following two questions:

  • How many of each penguin species live on which of the three islands?
  • How can the three different penguin species be distinguished?
  • Does the population change over time?

Analyze the type of task in the why of the what-why-how framework (Lecture 1: Slides 42 - 47), by determining at least one target - action pair for each question.

Write your answers in the file "why.md".

Part 2

Now think of two questions that you could answer with this dataset.

Write them in the file "why.md".

Task 3: The How (50%)

Part 1

Consider only the first of the scientist's questions in Task 2.1: How many of each penguin species live on which of the three islands? Please, implement either a scatter plot or bar chart to answer the question. Write your implementation into the index.js. The data has already been loaded for you. You can have a look at the structure of the data in the penguins.csv or the developer console of your browser.

Write your reasoning as to why you chose the one visualization over the other in the file "how.md".

Part 2

Design (not implement) a system of interlinked visualizations that are able to answer the data scientists questions posed in Task 2.1. Draw a sketch either by hand (and scan / photograph it) or with a graphics program and evaluate it critically. Put your drawing / sketch as image into this folder.

Determine the marks, channels used, as well as sensible interactions of manipulation, facetting or reducing the data that would help towards the set task.

Write your answer in the file "how.md".
