Assignment 4

Text and Set visualization

Analyzing movie genres

In this task you will create a system to analyze movie genres via the short texts that describe the movies. You will implement and coordinate both text and set visualizations to find out about differences between genres and genre combinations.

Your system should be able to answer the following questions:

  1. Are there textual differences - in wording - between different genres or genre combinations?
  2. Which genre combinations are there? And how often do they occur? Do films usually belong to multiple or only one genre?
  3. Can the provided embedding - created with Nomic Embed and t-SNE - capture the differences in genre? For which genres does it work better? For which less so? Can you think of an explanation why?

The data has already been loaded for you in index.js. We are logging it into the console for you to analyse.

Requirements

  1. Implement at least one text and one set visualization side-by-side (so both views are visible at the same time). (50%)
  2. Implement interactions between the visualizations, e.g., selecting a genre in one could trigger a filter in all visualizations. (20%)
  3. Answer the questions (10%)
  4. Describe and defend your design (20%)

Hints

If you want, you can use the provided functionality for creating word clouds. The function is already loaded for you in the document_embedding.js. The function wordcloud(svg, word_counts) expects a d3 selection as svg and an array of word counts in the format [[word1, count], [word2, count]...] as word_counts. For tokenization, feel free to use the function documentToWords(text) that receives the raw text as input and returns an array of single words.

If you want to use tfidf, you can use the tfidf(word_array, idf). word_array is an array of word counts. idf is a map of inverse document frequencies that you can calculate using the function inverseDocumentFrequency(grouped_words). The grouped words is an array of arrays of words [[word1, word2, ...], [word3, word 4...]] where each word array represents one group that will be contrasted with the tfidf measure.
