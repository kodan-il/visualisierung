Assignment 3

Time Series & Parallel Coordinates

You have seen several techniques for visualizing time series data in the online lecture and been introduced to parallel coordinates, a plot to analyze multi-attribute relations. In this assignment, you're going to visualize weather data using these two types of visualizations and connect them with interaction techniques.

The weather data is loaded for you from the csv file in the index.js. The code can also be used to load multiple files at once, even though only one file is actually loaded. You can also try to load the stock data to test how it works. The loaded data is printed to the console. Have a look at the data that is availabe and analyze the attributes to make the best decisions for your newest design.

Task: Create a coordinated multi-view to analyze the weather data.

It is your task to design and implement the visualization system that allows the user to answer the following questions:

  1. In which year and which weather station the lowest temperatures have been measured?
  2. At which stations the air pressure is lowest? Are there seasonal changes in air pressure?
  3. Is there some kind of relation between temperature and humidity?

The requirements for the system:
  1. Implement a parallel coordinate system (20%).
  2. Implement a suitable time visualization (20%). Please defend your choice in the design_choice.md (10%).
  3. Connect the visualizations with brushing and linking (25%).
  4. Add a possibility to filter per station (10%).
  5. Describe the marks and channels of both visualization types in the marks_and_channels.md (10%).
  6. Actually answer the questions in the answers.md (5%).
